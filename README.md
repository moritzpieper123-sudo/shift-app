# Shift – Arbeitszeit

Eine einfache Arbeitszeiterfassung fürs iPhone. Shift ist eine Web-App: in Safari öffnen und über **Teilen → Zum Home-Bildschirm** installieren.

- Arbeit starten, pausieren und beenden (der Timer läuft weiter, auch wenn die App geschlossen ist)
- Startzeit nachträglich ändern, vergessene Schichten nachträglich beenden
- Kalender mit Stunden pro Tag und Zeitleiste für jeden Tag
- Schichten und Pausen nachtragen, bearbeiten und löschen
- Statistik pro Woche (mit KW) und Monat
- Export als PDF-Arbeitszeitnachweis mit Unterschriftsfeld
- Backup speichern und wiederherstellen

Alle Daten bleiben nur auf dem eigenen iPhone.
