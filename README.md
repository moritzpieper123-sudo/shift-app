# Shift – Work Time

A simple work time tracker for iPhone. It is a web app: open it in Safari and use **Share → Add to Home Screen**.

- Start / pause / stop your shift (the timer keeps running when the app is closed)
- Calendar with hours per day and a timeline for each day
- Add or edit shifts and breaks afterwards
- Week and month charts
- Export a week or month as PDF

All data is stored only on your phone.
